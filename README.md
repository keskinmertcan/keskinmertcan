I'm a full stack developer focused on designing and building **reliable, scalable and practical software systems**.

I enjoy working on projects where multiple technologies need to operate together — backend services, databases, desktop applications, mobile clients, hardware integrations and cloud infrastructure.

## 🧠 How I Approach Engineering

```text
Understand the system
        ↓
Map the architecture
        ↓
Find the weak points
        ↓
Design the solution
        ↓
Build
        ↓
Break it
        ↓
Fix it
        ↓
Make it reliable
```

I care about software that survives outside the development environment.

That means handling things like:

**timeouts · network failures · concurrency · device failures · recovery · data integrity · deployment · monitoring**

Because software isn't finished when it works once.

It's finished when it **keeps working when something goes wrong**.
